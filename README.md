# Sistem Absensi Digital — MA Nahdhiyah Talun (Siap GitHub Pages)

Paket ini sudah disesuaikan khusus untuk **GitHub Pages** (menggunakan path relatif `./` sehingga berjalan lancar di alamat subpath seperti `https://username.github.io/nama-repo/`).

## Cara Upload & Aktifkan GitHub Pages:
1. Ekstrak file ZIP ini di komputer/HP Anda.
2. Buat repositori baru di **GitHub** (misalnya bernama `absensi-ma-nahdhiyah-talun`, set ke **Public**).
3. Klik **Add file -> Upload files**, lalu unggah seluruh isi hasil ekstrakan (`index.html`, `manifest.json`, `sw.js`, `.nojekyll`, `README.md`, dan folder `icons/`) langsung ke root repositori.
4. Klik **Commit changes**.
5. Masuk ke tab **Settings -> Pages** di repositori tersebut:
   - Pada **Source**, pilih **Deploy from a branch**.
   - Pada **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu 1-2 menit hingga URL aktif muncul (`https://username.github.io/nama-repo/`).
